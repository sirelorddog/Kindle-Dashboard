# Kindle-Dashboard
little dashboard
requires flask, pillow, and playerctl. optional stuff is: wpctl / pactl / amixer / xdotool.

**how to setup:**
**1.** download kindle-dash.zip, extract it anywhere on your pc (home folder is recommended)
**2.** run the ./start.sh in the kindle-dash folder
**3.** download the plugin (dashboard.koplugin)
**4.** put the plugin in ur koreader plugin folder
**5.** open koreader, go to the tool icon, find PC Dashboard.
**6.** have fun!
